# 01 — tag 字符集收紧到 [a-z0-9-]

**What to build:** 一个 tag 里不可能出现选择器用到的分隔符,于是「按名字寻址一条泳道」这件事
成立。今天 canonical 谓词**不拒绝逗号**,而 recall 在解析前按逗号切分 id,所以名字里带逗号的
泳道没有可用的地址。

对应 spec:D2 后半。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] canonical 谓词收紧到 `[a-z0-9-]`:NFC、小写、非空、不以 `-` 开头或结尾
- [ ] `,` `/` `#` `*` `.` 各有一条拒绝用例,错误消息指名违规字符
- [ ] 实测生产库 104 个已声明 tag 全部落在此字符集内,收紧不破坏存量——
      在票面记下这个测量,并在实现时**重新测量**(库是活的)
- [ ] 工具描述里的 canonical 说明同步改成字符集口径
- [ ] 突变:放行任一分隔符,必须有测试变红
