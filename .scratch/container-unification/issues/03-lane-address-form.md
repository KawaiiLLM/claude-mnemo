# 03 — 泳道地址 `E<n>/#<tag>`

**What to build:** 一条泳道能按**名字**被选中,而且选中它和操作它是同一句话。

对应 spec:D2 前半。

**Blocked by:** 01(字符集)

**Status:** ready-for-agent

- [ ] `E<n>/#<tag>` 进 recall 的地址语法,与既有 E 形式不冲突
- [ ] 它同时是 recall 的读选择器和 remember 的写目标
- [ ] `E<n>/L<n>` 序号形式保留为交互挑选用,但**不作为可粘贴地址**——文档里说清
- [ ] `E<n>/#`(空 tag)与非规范 tag 拒绝并指名
