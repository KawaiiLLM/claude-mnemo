# 07 — 泳道 `clear`

**What to build:** 一条作废的泳道可以被清空:成员不再带它的 tag,归属于它的边一并消失,
之后 `delete` 生效。清完不留孤儿。

对应 spec:D5 + D5b。

**Blocked by:** 03(地址)

**Status:** ready-for-agent

- [ ] 从每个成员 turn 的 tags 里摘掉这个词,经归属推导写回,不裸 UPDATE
- [ ] **删掉**两侧都解析到这条泳道的边行——不是把两侧还原成未结算
- [ ] 侧的解析走**端点的归属段**(复用既有的 `ownsSide` 判断),**绝不比较裸字符串**:
      两个段都声明 `alpha` 时,一条 E1/alpha→E2/alpha 的边两侧都写着 `alpha`
- [ ] **删完之后恢复 bare 行**:被清空的 pair 按引用方分组,重扫正文,正文仍指名则恢复
      bare `text-ref`。复用既有的撤销路径修复,不另写。否则会把一个已修的缺陷引回来
- [ ] 两类边要 force,不是一类:跨泳道边;**半结算边**(一侧是它、另一侧是 `''`)
- [ ] 任务级 `clear` 在该任务**还有已声明泳道时拒绝**并列出它们——写闸禁止「带泳道 tag
      却不带任务 tag」的 turn,而边侧根本不持有任务 tag,所以隐式递归既不安全也无谓词
- [ ] 突变(侧解析):**必须先断言不带 force 时拒绝**、打印对面泳道、边行原封不动,
      再断言 force 删掉。只跑 force 是无效突变——两种逻辑最终存储完全相同
- [ ] 突变(bare 行):被删的行是该 pair 最后一条关系、引用方正文未变时,bare 行必须回来
