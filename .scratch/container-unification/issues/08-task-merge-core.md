# 08 — 任务 `merge` 主干(无重名)

**What to build:** 一个任务能把成员、泳道和身份交给另一个任务然后消失。本票只做**无重名**场景。

对应 spec:D6。

**Blocked by:** 05(create 统一)

**Status:** ready-for-agent

- [ ] **成员按归属选,不按 tag**:`create(members=[...])` 只写 `segment_members` 不写任务 tag,
      按 tag 选会一个都搬不到,随后级联删除让 turn 变成无归属——静默丢成员。
      搬完要补齐 tags,让两个存储一致
- [ ] **顺序是硬的:泳道先于成员**。把带 `[from, alpha]` 的成员改成 `[into, alpha]` 时,
      若 `alpha` 仍只声明在 from 名下,写闸会拒绝
- [ ] 最后一步「from 离开注册表」的守卫与删除**写在一起**,与既有的 `undeclareEmptiedLane`
      同一形状——上移守卫就会抛,而不是留下一个谁也删不掉的任务
- [ ] 会话挂靠**不迁移**,随源任务级联消失
- [ ] 回执报出交出了多少成员、多少泳道
- [ ] 突变(顺序):把泳道搬移挪到成员重写之后,必须有测试变红。
      **fixture 的成员必须带一个已声明的泳道 tag**,否则错误顺序也能通过——写闸不会被触发
- [ ] 突变(成员选取):改回按 tag 选,必须有测试变红。用一个 `create(members=[...])`
      播种的、不带任务 tag 的成员构造,并同时断言目标端归属与源端清空
