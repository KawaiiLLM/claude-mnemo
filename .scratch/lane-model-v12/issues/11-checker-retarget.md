# 11 — 校验器重新瞄准:连通性、旁路候选、耦合报数

**What to build:** 校验器的报表对齐新模型的两条原则,并给出耦合的分组事实 —— 全部是删除与重新瞄准,不新增报表类别。

**Blocked by:** 10。

**Status:** done — landed, not released

- [ ] **连通性**:域改为「两侧 tag 同为该 lane 的边」;新增一行「closed lane 的终点是否被外部节点引用」。实测:54 条 closed lane 里 32 条(59%)通过,22 条被标记,其中含 20 成员的 `relation-vocabulary` 与 15 成员的 `workflow`。provisional lane 不报。
- [ ] **旁路候选**(原路径报告):改在**段的全图**上做传递归约。输出叫**结构性旁路候选**,同时列出直接边与替代路径,**不指定该删哪一条** —— 三种处置取决于「各条路径分别提供了什么信息」,那是内容事实,校验器手里没有。实测密度:全图 27/484(5.6%),lane 内 13/354(3.7%)。
- [ ] **耦合报数**:每条 lane 的跨 lane 边按三组计数(verify/override/narrow/extend | ground | consume/index),**不产出机器判决**。「较少」没有分母也没有阈值,不发明门限。**复用被删除的报表 3 的槽位、类型与渲染器**,不新增加载结果、渲染段落或结算提示词契约。
- [ ] **归属告警**:无归属簇的定义改为「**两侧 tag 为空串的边**」,那就是结算自己的待办队列;比例告警不变。
- [ ] 三组计数在一个三 lane 夹具上精确;旁路候选的输出同时含直接边与替代路径。

## 票 03 落地后加的一条

**E2 在任何存活数据库上已经不可达。** 票 03 把 `supersedes` 与 `refutes` 一起移出了 schema 的 CHECK,写入面也造不出词表外的关系词 —— 于是没有任何存储行能携带词表外的词,也没有任何写入面能创造一个。E2 这个错误类目前只有测试夹具靠 `PRAGMA ignore_check_constraints` 才能触发。

**结算的教学面把错误类当作封闭清单枚举**(`lane_check` 与 `commit` 的描述都列着 `(E2)(E3)(E4)`),所以留着 E2 等于教一个永远不会到来的拒绝。本票要裁:E2 是删,还是保留成「迁移前遗留数据的读侧诊断」并在教学面上说明它不会在新写入上出现。
