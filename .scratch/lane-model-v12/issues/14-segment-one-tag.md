# 14 — 段一个全局唯一 tag,归属自动推导,tags 的写入闸

**What to build:** 一个段以一个全局唯一的 tag 标识,一个 turn 的 tags 里出现哪个段的 tag 就属于哪个段 —— 显式挂靠退役,多匹配在定义上不可能。

**Blocked by:** None — can start immediately.

**Status:** done — landed, not released

实测(只读):九个 open 段里两个各带**一个** curated tag、与任何段零冲突,其余七个一个都没有;29/21/18 个 tag 的段与全部全局冲突(`scene-data-v2` 4 个段、`san11-spec-mvp-scope` 4 个…)都在 delivered / closed 那批。所以这不是收缩,是**给活的容器补名字**。

- [ ] 段的 tag 从一组收成**一个**,并在全局唯一。schema 与写入面同步;`retag` 的语义随之变成「改这一个」。
- [ ] **迁移**:七个没有 tag 的标准容器由人工指定名字(不要自动生成);已交付/已关闭段的派生 tag 列表**清空** —— 它们不再收新成员,唯一性对它们无意义,而一个 29 元的列表会让自动挂靠无从判断。那些词本来就还在成员 turn 自己身上,不丢信息。
- [ ] **归属自动推导**:turn 的 tags 里出现某个段的 tag,即属于该段。`note(segment=...)` 与 `remember(assign)` 的显式挂靠退役。
- [ ] **第二个段 tag 拒绝**:`tags` 里同时出现两个段 tag 时,写入拒绝并点名冲突的两个段 —— 让「不存在多匹配」成为结构保证而不是约定。
- [ ] **lane tag 需要它所属段的 tag 同时在场**:写一个 lane tag 而该段的 tag 不在同一个 turn 的 tags 里,拒绝并点名缺的那个段 tag。**「无归属的 turn 不能进任何 lane」由此成为结构保证。**
- [ ] **卡片清理**:删掉 `- tags:` 与 `- type:` 两条直方图行(它们渲染成员的历史分布,在新模型下看起来像词表而不是);段自己那一个 tag 移进卡片头;腾出的预算归 `- lanes:` 行。
- [ ] 测试:两个段不能共用一个 tag;一个 turn 带两个段 tag 被拒;带一个段 tag 的 turn 自动成为该段成员;不带任何段 tag 的 turn 是无归属;卡片不再出现直方图行、头部出现段 tag。
- [ ] 突变验证每一条声明为承重的性质。

## tags 写入闸的其余部分(从票 10 移来)

- [ ] `tags` 只接受该 turn 所属段的**那一个段 tag** 与该段内**已声明的 lane tag**;其余拒绝并列出当前合法集合。**不做成 schema 枚举** —— MCP 的工具形状在连接时公布一次,而 lane 由结算中途声明、挂靠也会中途变化,枚举当场过期。词表已经在花名册与段卡片里注入。
- [ ] **前缀规则**:机器写的 tag 带前缀(`compact:` / `invalidated:` / `delivery:`,由 hook 直接写库,不经这道闸);`checkCanonicalLaneTag` 增一条 —— **含前缀分隔符的值不得声明为 lane 或段 tag**。
- [ ] **遗留的自由 tag 值一律不清除**,只禁新写;未声明即非 lane,在归属计算里天然为零。
- [ ] **`declare` 在声明前报出会被追溯征召的既有 turn 数**(实测 `spec` 153、`citation-edges` 124、`timeline` 123),让「这个名字太泛」在声明当下就看得见。
- [ ] 主 agent 与结算两侧的 `.describe()` 分别写。

## 与票 08 的关系

**票 08(边的写入闸与两侧门面)阻塞于本票**:它的第二条按侧检查要求「该侧的 tag 已在该侧端点所属的段中声明」,而那个模型由本票建立。两票也争用同一批文件(`note.ts` / `definitions.ts` / `turn-phase.ts`),**必须串行**。

## 词表预算(实测,只读)

段卡片 `fields` 块的页预算是 **2000 token**,E60 今天渲染出来 **1972** —— 已经贴着上限。删掉两条直方图腾出 **186 token**;一份判据执行到位的 lane 词表(20–30 条,带地址)约 **160–250 token**,正好装得下。**77 条那份是 625 token,怎么渲染都塞不进去** —— 装不下是增殖病的症状,不是渲染格式的问题。**暂不设计降级方案。**
