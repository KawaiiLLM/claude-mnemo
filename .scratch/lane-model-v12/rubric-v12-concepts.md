# Memory Rubric v12 — 第一部分 · 概念

注入主 agent 与结算两侧,逐字节相同。**这一部分只描述,不出现祈使句。**

---

**节点**:一个节点即一个 turn —— 一次用户 prompt 及其后续回答。

- **归属节点**:节点自身的 tags 中带有一个或多个已声明的 lane tag,即属于这些 lane。
- **无归属节点**:不属于任何 lane。
- **无效节点**:被 skip / rewind 的 turn,其上所有边视为作废。节点只因 skip / rewind 失效。

**段**:一个长期存在的任务容器,一个 turn 至多属于一个段。段有一组人工策展的 tag,成员 turn 的 tags 带有它们全部。lane 的范围就是段 —— **一条 lane 的身份是「段 + tag」**,同名 tag 分属两个段,是两条 lane。

**lane**:段任务下明显可分离、可持续的子任务,以一个 tag 唯一标识。

- **成员**由节点自身的 tags 决定;两侧身份相同的边构成这条 lane 的**内部 DAG**。一个成员可以尚未接入那个 DAG。
- 正常的 lane 至少两个成员。一条新声明的 lane 可以暂时只有 0 或 1 个,成员达到两个后不再是这种暂态。
- **closed**:lane 的最新成员是它的终点,终点即通过 index 宣告收敛的节点。「最新」指**所有归属成员中最新的那个**。一条 lane 可以有多个中间 index,但只有最新成员发出 index 时才是终点。宣告收敛的是**弧尾**所指的那条 lane,弧头指向哪里不影响判定。
- **open**:最新成员不是终点,表示尚未收敛。
- **共用节点**:一个节点可以属于多条 lane;多条 lane 的关系用多条边分别表达。

**边**:一条边表示两个节点之间的一个关系,方向由引用方指向被引用方。两端必须是不同节点。

- **弧尾**:有向边的起点,即**引用方**属于哪条 lane —— 主体。
- **弧头**:有向边的终点,即**被引用方**属于哪条 lane —— 客体。
- 某侧的 tag 必须也在该侧节点自身的 tags 中。
- **连通成员**:被两侧身份相同的边连起来的归属节点。两侧身份不同即跨 lane 关系,跨 lane 关系不建立连通。
- **未结算的边**:两侧同时空缺,是合法的草稿态,不参与连通与收敛的任何计算。
- 两个节点之间可以存在多条边。

**七个关系词**:

- **verify**:被引节点的主要结果被本节点验证、支持。
- **override**:被引节点的主要结果被本节点否决、撤回、替换。
- **narrow**:被引节点的主要结果仍然适用,本节点对细节做出修正、限制。
- **extend**:被引节点的主要结果仍然适用,本节点对其拓展、补充。
- **ground**:本节点的工作依赖被引节点的成立,它若倒下,本节点随之倒下。
- **consume**:消费其他节点的产出,不为其正确性担责。
- **index**:本节点阶段性收敛,通过指向**一个或多个**节点表达汇聚、索引、整理前面工作中有效的部分。

词义与两端属于哪条 lane 无关。**七个词里只有 index 参与 open / closed 的判定;其余六个不改变节点的有效性,也不改变任何 lane 的状态。**

**字段**:一个 turn 的笔记有三个字段,各司一职。

- **title** —— 索引。一句话说明这一轮在做什么,足以在只有标题的列表里被认出来。不是结论。
- **content** —— 结论。这一轮产生的每个有用的决定,以及每个被否掉的选项与它的理由。假定标题刚被读过。过程细节属于 replay,不属于这里。
- **insight** —— 可复用的经验。这一轮被忘掉之后仍然成立的教训,在本项目内或之外。不是这一轮的结论。

**type**:封闭词表,一词一义。

- **discuss** —— 探讨了选项、产生了理解,但没有落定裁决;倾向性不等于承诺。
- **research** —— 查阅了外部来源、代码或文献:关于世界或代码库现状的事实。
- **measure** —— 这一轮产出了一个可复检的结果:实验、统计、计数。
- **design** —— 立下或修订了一个此后要遵守的承诺:机制、契约、阈值。
- **correction** —— 纠正了一个先前的错误结论或方向;错在**判断**上。
- **implement** —— 已定的设计写进了新工件:代码、文档、测试。
- **refactor** —— 减法与改形:能力被移除、形态被迁移,没有新的行为承诺。
- **fix** —— 修好一个缺陷,让既有的承诺重新成立。
- **delegate** —— 工作被派给子代理或外部执行者。
- **review** —— 一份产物被对照它的标准检查。
- **ops** —— 交付(发布、提交、spec、票)与运维(探针、重启、修理)。

一个 turn 可以带多个 type。没有匹配的词时 type 为空。

**tags**:只有**已声明的 lane tag** 与**该段的策展 tag** 参与 agent 侧的语义。带前缀的 tag 属于机器的命名空间,不参与 lane。

**注入进来的块是索引,不是记忆本身** —— 没出现在注入里,不等于没有记录。
