# Rubric v12 — lane sections, SHARED half

注入主 agent 与结算两侧,逐字节相同。判据与机制在结算专用的另一半。

---

**lane**:段任务下明显可分离、可持续的子任务,以一个 tag 唯一标识,范围为段,形式为两侧 tag 同为该 lane 的边所连成的 DAG。lane 至少两个节点;**一条新声明的 lane 可以暂时只有 0 或 1 个成员**。

**节点**:一个节点即一次对话。

- **归属节点**:节点自身的 tags 中带有一个或多个已声明的 lane tag,即属于这些 lane。
- **无归属节点**:不属于任何 lane。**结算完成后**它不应该有边;要表达关系,先归属或声明一条满足定义的 lane。
- **无效节点**:被 skip / rewind 的 turn,其上所有边视为作废。

**边**:一条边表示两个节点之间的一个关系,方向由引用方指向被引用方。

- **弧尾 tag**:有向边的起点,即**引用方**属于哪个 lane —— 主体。
- **弧头 tag**:有向边的终点,即**被引用方**属于哪个 lane —— 客体。
- 某侧的 tag 必须也在该侧节点自身的 tags 中。
- **连通成员**:被两侧 tag 同为该 lane 的边连起来的归属节点。两侧 tag 不同即跨 lane 关系,跨 lane 关系不建立连通。
- 两个节点之间可以存在多条边(不同关系,或不同的两侧 tag 组合)。
- **不允许自引**:一条边的两端必须是不同的节点。连通的单位是节点,同一个节点内部的设计与落地不需要掰成两半。
- **未结算的边**:两侧 tag 同时暂缺。**主 agent 写下的边一律如此 —— 它只写关系词,不写两侧 tag,lane 不归它管。** 未结算的边**不参与**连通、收敛、耦合的任何计算,由结算补齐或撤回。**只有一侧有 tag 是非法的**,两侧要么都有、要么都没有。

**七种关系**:

- **verify**:被引节点的主要结果被本节点验证、支持。
- **override**:被引节点的主要结果被本节点否决、撤回、替换。
- **narrow**:被引节点的主要结果仍然适用,本节点对细节做出修正、限制。
- **extend**:被引节点的主要结果仍然适用,本节点对其拓展、补充。
- **ground**:本节点的工作依赖被引节点的成立,它若倒下,本节点随之倒下。
- **consume**:消费其他节点的产出,不为其正确性担责。
- **index**:本节点阶段性收敛,通过指向多个节点表达汇聚、索引、整理前面工作中有效的部分。

**closed lane**:一条 lane 的最新成员是它的终点,终点即通过 index 宣告收敛的节点。一条 lane 可以有多个中间 index,但只有最新成员发出 index 时才是终点。**宣告收敛的是弧尾 tag 所指的那条 lane**;弧头指向哪里不影响收敛判定。

**open lane**:最新成员不是终点,表示尚未收敛。

**converge**:一个节点可以属于多条 lane;多条 lane 的关系用多条边分别表达。
