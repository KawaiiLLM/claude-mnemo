# Lane model v12 — spec

**状态**:未实现。lane-declaration 批次(12 票 + 2 张修理票)已落地未发版,本 spec 建立在它之上并改写其中若干条。

**正文来源**:模型的权威文本是用户自己写的两份 rubric ——
`rubric-v12-shared.md`(主 agent 与结算共享)与 `rubric-v12-settlement.md`(结算专用)。
本 spec 与它们冲突时以 rubric 为准。

**贯穿全篇的约束**:**选举机制与校验器只做最小调整。** 这套定义还没有被真实数据验证过,凡是「重新设计报表 / 重新设计评分」的动作一律推迟到验证之后 —— 见最后一节。

---

## 问题

v11 把 lane 建成了一个**相位内**的概念:五个同相位词、三个跨相位词,`extends`/`narrows` 强制带 tag,一条边只有一个 tag 集合。三个后果:

1. **相位闸几乎什么也不拦。** 实测:「多相位 turn 任一配对合法」这个逃生口开着时,全库存活的人写边里**只有 1 条**不合法;关掉逃生口则 309/609(51%)不合法。**让图合法的是逃生口,不是相位轴。**
2. **跨 lane 的关系存不下来。** 单一 tag 集加上「tag 必须同时在两端节点上」,意味着一条从 lane A 指向 lane B 的边只能写成无 tag —— 它跨了哪两条 lane 这个事实丢失。全库 411 条 consume 里只有 3 条是两侧都有 lane 且不同的,不是因为罕见,而是因为写不出来。
3. **一个词的 scope 与它的 tag 重复。** `ground → 同 lane` 与 `consume → 非同 lane` 只靠 scope 区分,而 scope 从两侧 tag 就能算出来 —— 这样的词携带零信息。

## 解法 —— 六个动作

1. **相位轴从关系词表中删除。** 词的含义与相位无关;`verify`/`override` 也不再要求引用方带取证 type。
2. **`refute` 并入 `override`**,词表从八个降到七个。取覆盖面大的名字:合并后的语义是「主要结果不再适用」,涵盖反驳、撤回、放弃、替换。
3. **一条边带两个 tag,每侧一个。** 弧尾 = 引用方所属 lane,弧头 = 被引用方所属 lane。多对多用多条边表达。
4. **归属来自节点自身的 tags**,不再从边推导。连通成员才需要两侧同 tag 的边。
5. **有边就必须有 lane。** 真正的无归属节点不与其他节点发生关系;要写边,先归属或声明一条合格的 lane。主 agent 写的边可以暂缺 tag —— 那是**未结算**形态,由结算补齐或撤回。
6. **scope 从七个词里搬到耦合规则里,只说一次。**

## 相对 v11 的变化清单

| v11 | v12 |
|---|---|
| 八词,分同相位/跨相位 | 七词,无相位约束 |
| `refute` 独立 | 并入 `override` |
| 无 tag 的 `override` = 全局否决(杀死节点) | **没有全局否决,没有节点死亡** |
| 带 tag 的 `override` 重开 lane | **没有重开机制** —— 最新成员不是 index 即 open |
| 一条边一个 tag 集合 | 每侧一个 tag |
| 成员资格由带 tag 的边推导 | 由节点自身 tags 决定 |
| `valid lane`(核心节点存活) | **删除**;质量信号并入连通性原则 |
| 单 source / 单 sink(E5,阻断提交) | **删除** |
| 自引:只允许裸 `ground` + 终点条件 | **删除整条规则** —— 连通的单位是节点,同一节点的设计与落地不需要掰成两半 |
| 判据含「周期较长」 | 只剩可分离、可持续 —— 累积量只能事后判,不能当声明门 |
| `supersedes` 冻结但仍在 schema CHECK 中 | 机械迁移为无 tag 的 `override`,词表条目与两处读取特判一并删除 |

## 实现决策

### D1 — 存储:边带两侧 tag

`memory_edges.tags`(JSON 数组)由两列取代:每侧一个可空的 tag。边的身份键随之变为 `(citing, cited, relation, 弧尾 tag, 弧头 tag)`,否则「两点之间可以有多条边」无法判断重复写入是否幂等。

`memory_edge_tags` 索引需要区分侧。

**为什么不是「每侧一个集合」**:8.8%(41/464)的现存带 tag 边携带多个 tag,拆成多条边的迁移代价很低,而集合会把「同 lane」判定从一次相等变成集合求交,并重新引入 v11 那套 exact-set 比较的全部歧义。

### D2 — 写入闸

按侧检查,每条拒绝点名缺口:

1. **canonical form** —— 沿用 D1(lane-declaration)的判据,拒绝而非静默规范化。
2. **该侧的 tag 已在该侧端点所属的段中声明。** 身份是 `(段, tag)`;两侧 tag 字面相同但分属两个段,**不是**同一条 lane。这是 lane-declaration 票 02 已建的检查在双侧模型下的重新瞄准。
3. **subset**:该侧的 tag 必须也在该侧端点节点自身的 tags 中。

**两侧 tag 都可以暂缺**,那是未结算的边。缺 tag 不是违规。

**自引边不再合法** —— 规则整条删除;迁移撤回全库唯一那条(`S15069/T1265 ground T1265`,跨相位年代的产物)。

### D3 — 声明

`declare` / `undeclare` 沿用 lane-declaration 票 01/02 已建的机械(canonical、与段策展 tag 防碰撞、undeclare 在仍有边携带该 tag 时拒绝),两处改动:

- **允许 0/1 成员的 provisional lane。** 声明发生在第二个成员出现之前,不能因此拒绝。连通性原则对它不适用。
- **结算侧的 `remember` 门面已在票 02 中获得 `declare`/`undeclare`**,不需要再动。

### D4 — 迁移(一次,随发版)

| 阶段 | 动作 |
|---|---|
| M-A | `tags` → 弧尾 = 弧头 = 原 tags。全库 966 个「(边, tag, 端点)」组合零 subset 违规,所以这是**无损**转换。多 tag 的 41 条拆成多条边。 |
| M-B | `refutes` → `override`;`supersedes` → 无 tag 的 `override`。155 条 supersedes 全部 turn→turn、全部无 tag,与现存 override/refutes **零同 pair 冲突**,方向一律是引用方=纠正者,因此不需要逐条语义分流。 |
| M-C | 撤回唯一那条自引边。 |
| M-D | 删除 `supersedes` 的 schema CHECK 条目,以及 `segment-rank.ts` 里把它当 corrector / rolled-back 读的两处特判。 |

**迁移绝对不得把节点自身的历史 tags 自动声明为 lane。** `citation-edges` 这个 tag 有 **123 个 turn 自身带着它,却只出现在 2 个带 tag 边的端点上** —— 自动声明会立刻造出 121 个连通孤点。哪些 tag 成为 lane 是人工裁决。

每个阶段写自己的持久收据,依据收据跳过,不从表是否存在推断。

### D5 — 选举:只做删除,不重新设计

- **候选资格排除整条删除。** 全局否决没有了,所以「被无 tag 的 override/refutes 指向即失去候选资格」这条规则失去依据。今天有 18 个存活 turn 靠它被排除,删除后它们重新入选。
- **`deriveLaneStates` 简化**:closed = 最新成员发出一条弧尾为该 lane 的 index;否则 open。事件归约、`dead`、`lastDeclarer` 全部退役。
- **tier ② 由「closed-valid 终点」变为「closed 终点」**,因为 validity 不存在了。
- **不做的事**:不重排层级、不调权重、不加新信号。

### D6 — 校验器:只做删除与重新瞄准

**删除**:

- **E5**(单 source / 单 sink)—— 它强制的是 v10 的一句话,v11 已经删掉那句;它今天还在阻断提交。
- **报告 3**(shared components / 多 lane 纠缠)—— 对应 v10 的 component emergence,v11/v12 无此原则。
- **报告 4a**(inter-lane interfaces + bypass)—— 对应 v10 的 minimality,已被节点对路径唯一性取代。

**重新瞄准**:

- **连通性报告**:域改为「两侧 tag 同为该 lane 的边」;新增一行「closed lane 的终点是否被外部节点引用」。0/1 成员的 lane 不报。
- **最小连通(报告 4b)**:改为在**段的全图**上做传递归约,报告冗余边及其替代路径;只报结构性旁路,不判断语义等价。
- **耦合报告(新,最小)**:每条 lane 的跨 lane 边按三组计数,**不产出判决**。
- **归属告警**:lane-declaration 票 09 的两条保留。无归属簇的定义随「有边必有 lane」改为「**两侧 tag 暂缺的边**」—— 那就是结算自己的待办队列。比例告警不变。

**不做的事**:不重新设计报表结构、不引入新的报表类别(包括「图里存在但注册表未声明的 lane」这条已知缺口,推迟)。

### D7 — rubric 按受众拆两半

- **共享半**(`rubric-v12-shared.md`):lane 是什么、节点三分类、边与两侧 tag、七个词、closed/open/converge。注入主 agent 与结算,**逐字节相同**,现有的字节一致性测试继续钉住这一半。
- **结算半**(`rubric-v12-settlement.md`):声明判据、结算职责、写入规则、耦合、两条原则。**并入现有的结算专用提示词**,不新建第三份工件。

主 agent 那边还需要一条许可,写在 `note` 工具描述里而非 rubric:**你可以写不带 tag 的边,lane 不归你管。**

### D8 — 不变的部分

结算的窗口与重试机械、段的定义与成员资格、note 的三个字段与预算、`type` 词表、控制台与 timeline 的渲染(除地址与 lane 视图随模型自然变化外)。

## 测试决策

按外部可见的拒绝与渲染断言,不断言内部调用。每个面一条:

- **写入闸**:三条按侧的拒绝各一条;一条两侧 tag 字面相同但分属两段的边被拒绝;两侧暂缺 tag 的边被接受;自引边被拒绝。
- **迁移**:在一个镜像真实形状的夹具上断言收据**行**,以及第二次运行是无操作;多 tag 边拆分后两侧一致;`supersedes` 迁移后不与既有 override 撞键。
- **选举**:候选资格排除删除后,原先被排除的节点重新进入;closed/open 由最新成员判定。
- **校验器**:E5、报告 3、报告 4a 的消失各有一条 grep 哨兵;连通性新增那行在两侧(有外部引用 / 无外部引用)各一条;耦合三组计数在一个三 lane 夹具上精确。
- **rubric**:共享半的字节一致性;结算半只出现在结算提示词里;两半合起来覆盖模型的每一节。

**每一条声明为承重的性质都要突变验证**:破坏它,点名变红的测试,再还原。存活的突变是发现,补测试再收工。

## 明确不做(以及为什么)

| 推迟的东西 | 理由 |
|---|---|
| 报表结构重新设计 | 定义未经验证,重设计可能白做 |
| 「图里存在但注册表未声明的 lane」报表 | 新报表类别,等验证之后 |
| 选举的层级/权重调整 | 只做删除 |
| 把 326 个待挂靠的 turn 一次性整理 | 见下,这是验证的一部分而不是它的前提 |
| `可分离` 的机器判决 | 没有分母也没有阈值,不发明门限 |

## 验证:怎样知道这套定义能不能 work

**这是 spec 的一部分,不是之后再说的事。** 顺序:

1. **发版并跑迁移。** 此时全库的边都是「弧尾 = 弧头 = 原 tags」,即全部同 lane,没有一条跨 lane 边 —— 这是基线。
2. **挂靠。** 326 个是 asserted 边端点里尚无 lane 的 turn(305 个在 E60);9784 个存活 turn 一条 asserted 边都没有,不需要处理。结算逐步做,或一次性整理。
3. **在挂靠后的图上跑三份报告**,读输出:
   - 耦合三组计数 —— `ground` 那 15 条跨 lane 是真耦合还是正常依赖?
   - 连通性 —— 54 条 closed lane 里有 22 条终点无人引用(含 `relation-vocabulary` 20 成员、`workflow` 15 成员),这些是真信号还是标注缺口?
   - 最小连通 —— 全图传递归约可删边 27/484(5.6%),lane 内 13/354(3.7%)。这个密度值不值得一条原则?
4. **读完再决定要不要继续投校验器。** 如果三份报告在真实数据上读起来是噪声,问题在定义,不在报表。

**基线数字(只读实测,发版前)**:存活 turn 10334;asserted 人写边 609,其中 600 条段内、0 条跨段;asserted 边端点 550 个,已有 lane 的 224 个;派生 lane 99 条,closed 54 条;lane 成员数中位 3、跨度中位 7.5、内聚中位 61%;E60 有 1537 个存活成员、75 个边 tag,比例告警的配额是 76.85,**还剩两条 lane 的余量**。
