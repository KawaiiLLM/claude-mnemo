5. 为什么 B/D 几乎无效——机械层的真正卡点
-----------------------------------------

四个段侧里有三个的座位在 tier ①/② 内就已经被填满，档②以下的任何重排都
结构性地够不着（arm A 的实测座位构成）：

  E60/old    35 席 = release 11 + declares-index 24     （declares-index 候选 57）
  E70/old    38 席 = declares-index 38                  （declares-index 候选 41）
  E60/recent 31 席 = declares-index 9 + indexed 22      ← 唯一边界落在 tier③ 内的格子
  E70/recent 39 席 = declares-index 3 + indexed 15 + corrector 18 + other 3
                                                        ← 候选池太浅，坐穿到 tier⑤

E70/old 与 E60/old：光 tier② 就超额认购预算，所以"把 corrector 提到 indexed 之前"
（B）和"在 ②③ 之间插一档"（C）对它们是恒等变换。
E70/recent：tier①–④ 的全部候选都已经坐上，档序是什么都一样——B 在 E70 上
+0/-0 正是这个原因，不是因为 corrector 不好，而是因为那里没有需要排序的竞争。
E60/recent 是全研究里唯一一个"档位重排能真正咬住"的格子；B/C 在 E60 上的
全部 diff 行都落在这个格子里。

这解释了第一轮"E60 结构上坐不进任何一条 corrector"的观察，并把它推广了：
E60 是因为档②已经吃光预算，E70/recent 是因为根本没有竞争。
B 这个改动在当前语料上没有可以发挥作用的地方。

D 唯一改动的地方是档内序：它在 E60/old 换掉了 8 进 7 出的 declares-index 行
（加权入度重排 tier②），在 E70 只换了 1 条。净 MUST +2，全在噪声内。
第一轮"93% 同分让 recency 接管"的诊断成立，但把同分打散之后排出来的新次序
并不更接近人的判断。

7. type 漂移审计（arm C 的前置条件，无论结论如何都报）
------------------------------------------------------

从 frozen/manifest.tsv 抽 15 条 07 月 design 型 turn、15 条 08-20 之后的
design 型 turn，打乱、隐去时间，交给一名独立盲判官做类别归类。

  窗口   n   arch  spec  review  impl  ops  analysis  other   含明确设计取舍
  07月  15   13     0      0      1     0     0        1      15/15
  08月  15    6     5      2      0     1     1        0      13/15

  arch 占比 13/15 → 6/15，two-sided Fisher p = 0.021。

判决（照直说）：**design 的语义确实漂了。** 07 月这个词几乎专指
架构/接口层面的取舍；到 08 月下旬它有三分之一变成"写规格/切票"、还混进了
评审与运维。但漂移是**扩类**而不是**变质**：两个窗口里"卡片中存在明确设计取舍"
的比例仍是 15/15 与 13/15，这个词没有退化成噪声标签。

因此 arm C 的数字是**有条件的**，条件有两层：
  - C 的 E60 增益全部来自 08-26..28 的 turn（diff 行全是 S15069/T18xx），
    正是 design 稀释得最厉害的窗口。也就是说，即使在最稀释的窗口 C 仍然有效，
    这一点对 C 有利；
  - 但反过来，如果这个词继续朝"spec/review/ops"扩，C 这一档会持续变宽
    （当前候选命中率已是 E60 0.32-0.34、E70 0.34-0.39），
    一档吃掉三分之一候选的分档，其区分力会随扩类单调下降。本研究测不出这个斜率。


8. 这份数据仍然定不了的事
-------------------------

1. **holdout 上 C 没有复现。** E60 net +7（p=0.039）、E70 net +1（p=1.0）。
   两种解释本研究分不开：(i) C 只对 claude-mnemo 这类任务有效；
   (ii) E70 的两个侧一个被 tier② 饱和、一个把候选坐穿，结构上没有给 C 留下
   起作用的空间。第 5 节的机械证据偏向 (ii)，但那不是一个统计判决。
2. **标签池对座位有偏。** D 批把"任何臂坐上的每一条"都标了，非座位行却只有
   S 批 70 条 + 第一轮的抽样覆盖。这让四个臂的 MUST 捕获率**绝对值**统一偏高
   （分母漏掉了没被任何臂坐上、也没被抽到的 MUST）。臂**之间**的比较不受影响
   （并集对四个臂对称），但表里 0.45/0.63 这类数字不能当作真实召回率读。
3. **B 这一臂在本语料上不可判。** 不是"无效"，是"没有被测到的机会"——
   三个段侧结构性不响应，第四个格子里 corrector 全员坐上。要判 B 需要一个
   预算恰好落在 tier③/④ 边界上的段。
4. **type 与标签不独立**（第一轮已记，本轮同样成立）：两者出自同一段文本，
   "design 预测 MUST"含同义反复成分。C 的价值主张只能是"已落库、选举没读的
   廉价代理"，不能读成"我们发现了重要性的原因"。
5. **一致性只是下界**：五名判官同族同代，共享盲区测不出；本轮精确一致 0.72
   比第一轮的 0.81 更低。
6. 未测：tags facet、insight 质量、E60/E70 之外的 segment、
   以及任何两个臂的组合（本设计刻意每臂只动一处，组合效应不可从中推出）。
7. D 的关系权重（2/1/0.5）与 C 的类型集合 {design, correction} 都是给定的，
   本研究没有搜索它们，也没有能力说它们是不是该量级的最优。
