# 01 — note 的写入护栏：身份、覆盖、跨会话

**What to build:** `note` 的三道护栏。写不存在的 turn 报错（**已具备，不用做**）；覆盖一条已有的笔记必须显式声明，否则失败；写别的会话的 turn 必须显式声明，否则失败。回执要能让调用方分清刚才是新写还是更新。

**Blocked by:** None — 设计已定案，前提已查实（见下）。

**Status:** ready-for-agent

## 前提调查（已完成，结论可直接依赖）

原先卡在「MCP 进程不知道自己属于哪个会话」。查实后结论是**知道，但不能直接用**：

| 标识 | 值（调查当时） | 谁看得见 |
|---|---|---|
| 环境变量 `CLAUDE_CODE_SESSION_ID` | `bbdd272a-…` | MCP 进程、hook 进程 |
| hook 载荷 `session_id` | `e8541c19-…` | 只有 hook |

两者**确实不同**：环境变量命名的是*进程*会话（resume／compact 后会换新），mnemo 按 hook 载荷里的*内容*会话记账。库里没有 `bbdd272a` 的会话行，而 turn 正往 `e8541c19` 的行里落——直接拿环境变量校验会把延续会话里的每一次 `note` 全部拒掉，也就是笔记静默停写。

hook 能同时看见两者，这一点已从 Claude Code 源码确认：它构造 hook 子进程环境时整个继承 `process.env`（擦除默认关闭，需显式开启）。因此**由 hook 建立映射**是唯一可行的位置。

一处必须尊重的边界：本机的 Claude Code 源码里只找到给 Bash 子进程设置该变量、以及 `/clear` 时重新赋值的地方，**没找到最初写进 CC 自身环境的位置**，本地 checkout 可能落后于在跑的版本。所以「环境变量缺失」必须当作受支持的正常情况。

## 设计

### D1 · 进程会话 → mnemo 会话的映射，由 UserPromptSubmit 每轮刷新

- 新增一张小表，以进程会话 id 为主键，存 mnemo 会话行 id 与更新时间。一个进程会话 id 只属于一个 mnemo 会话；一个 mnemo 会话在其一生中可以有多个进程会话 id（每次 resume／compact 换一个）。
- UserPromptSubmit 处理器每轮 upsert 一次。选这里而不是 SessionStart：resume／compact 会中途换 id，只在会话开头记一次会记成陈旧值。
- 环境变量缺失时**跳过记录**，不报错、不影响该 hook 的其它工作。

### D2 · 身份只由 MCP 入口注入，其它调用方一律「未知」

- 调用方身份作为一个显式选项传给工具处理器的构造，**只有 MCP 服务的进程入口会提供它**。
- worker 自用的工具通道绝不能带身份。worker 是被 hook 拉起的，会继承那个 hook 的环境变量，于是会「看起来像」某个会话——把身份的来源限制在 MCP 入口，这个陷阱就不存在。
- 身份**无法确定时放行**。没有身份不等于身份不符；拒绝会把任何没覆盖到的路径变成静默停写，那是本项目最不能接受的失败。

### D3 · 覆盖必须显式声明

- 判据用现成的：`getShadowNote` 返回非空即「这个地址已经有一条笔记」，它已经在写事务内被读出来了。
- 未声明覆盖而地址已有笔记 → 失败，错误信息要说清「已有笔记，确认要替换就带上该参数重发」。
- **与裁决 26 的冲突要一并处理**：现行提示词写着「后来的结果改变了它就再发一次，新的替换旧的」，加了强制参数之后这句话必须改。框架块有 500 token 硬上限且已用到 499，所以要从别处腾字，不能只加不减。MCP 工具描述同步改。

### D4 · 跨会话必须显式声明

- 地址所属会话 ≠ 调用方会话，且未声明 → 失败。
- 合法的跨会话写入目前**不存在**：泄压阀列表与当前 turn 行都是按会话发放的。所以这个参数是纯护栏，正常使用永不触发。生产实测 278 次调用 0 次跨会话。

### D5 · 回执区分「新写」与「更新」

- 新写与更新必须返回可区分的回执。现行实现两者都以 `Noted ` 开头，只在句尾附一句「替换了上一条」。
- **务必同步改判定成功的谓词**：试运行指标靠「回执是否以 `Noted ` 开头」判断写入成功。改了措辞而不改这个谓词，会把每一次更新记成失败。这是本票最容易漏的一处。

### D6 · 顺带清理

- `src/mcp/note.ts` 里那段声称「MCP 服务不被告知调用方会话」的注释已被证伪，替换掉。同一段里关于「不带模型身份」的那半仍然成立，保留。
