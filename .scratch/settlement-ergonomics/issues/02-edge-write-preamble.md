# 02 — 写边调用序言

**What to build:** 结算提示里出现一段**可以直接抄**的调用序列,让 agent 在写边之前就拿到
它需要的读,而不是靠被拒绝来发现前置。

对应 spec:D2。前置修复 `720ac49` 已经把边的形状改对了,本票建立在其上。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 序言给出读一个 turn 现有边的完整调用,**显式带足够大的 `turn` 预算**
- [ ] 序言写明「若 relations 被截断则加大预算重读」——默认预算会截断高入度 turn,
      而截断不记完整读授权,写边照样被拒
- [ ] 读泳道形状只给**单条**形式;不得出现 `E<n>/L*`(该路由不接任何预算参数)
- [ ] 提示渲染测试断言这三点各自存在
